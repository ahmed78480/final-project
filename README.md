# Platformer Game
This is a platformer game built with Pygame.

## Features
- Player movement and jumping  
- Enemies that shoot bullets  
- Tiles, spikes, and platforms  
- Start menu and game over screen  
### Controls:
- use WASD or the arrow keys to move your player.
- use the X button to shoot your enemies
- when your health reaches 0 the GAME OVER screen will appear press R to restart the level.
- if you want to manually restart the game press O to get to the GAME OVER screen and reset your game.
